## Estrutura do Projeto

- `app.py`: Código principal para a interface Streamlit e lógica do chatbot.
- `data_loader.py`: Script para carregar e indexar dados dos jogos no Qdrant.
- `furia_matches_24.txt`: Base de dados com informações sobre os jogos do time principal de CS2 da FURIA em 2024.
- `requirements.txt`: Dependências necessárias para o funcionamento do projeto.
